 ✅ Sửa lại hàm save_bytes_image(...) để dùng path nội bộ:
import os

def save_bytes_image(image_bytes: bytes, file_path: str):
    """
    Lưu ảnh bytes vào đường dẫn thực tế (nội bộ).
    Ví dụ: static/cropped/abc.jpg
    """
    # Đảm bảo thư mục tồn tại
    os.makedirs(os.path.dirname(file_path), exist_ok=True)

    # Ghi file
    with open(file_path, "wb") as f:
        f.write(image_bytes)

✅ Khi nào dùng PlateRequest (class, Body)?
🔹 Dùng khi:
Bạn truyền dữ liệu dạng JSON phức tạp (nhiều trường, hoặc có nested field).

Dữ liệu được gửi trong phần thân (body) của request, thường là trong POST/PUT/PATCH.

Khi bạn muốn tái sử dụng cấu trúc input nhiều lần hoặc kiểm tra schema.

🧠 Ví dụ:

✅ Khi nào dùng From Query, From Path, From Header?
🔹 Dùng khi:
Dữ liệu là tham số đơn giản (str, int, bool...), dễ gán trực tiếp.

Dữ liệu nằm trên URL (query string) hoặc đường dẫn, thường dùng với GET method.

Dữ liệu cần dễ dàng test/truy cập qua trình duyệt hoặc curl.

🧠 Ví dụ:
@router.get("/search")
async def search_plate(plate_number: str = Query(...), date: Optional[str] = Query(None)):
    ...
🔁 So sánh nhanh
Thuộc loại	Từ Body (PlateRequest)	Từ Query/Path/Header
Dùng khi	Nhiều field, cấu trúc phức tạp	Tham số đơn giản, lọc
Method thường dùng	POST, PUT, PATCH	GET, DELETE
Truy cập từ client	Gửi JSON	Gửi URL query/path
Ưu điểm	Gọn gàng, dễ validate	Dễ test, dùng trình duyệt
